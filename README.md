# 真写 for iPhone

iPhoneのタッチ操作に合わせて専用化した、ローカル保存型の写真反転ビューアです。

## 主な機能
- 写真追加ボタンからiPhoneの写真ライブラリ／ファイル選択画面を開いて複数読み込み
- IndexedDBへ端末内保存し、次回起動時に復元
- 追加順・古い順・ランダム順
- 一覧サムネイルの水平反転
- ビューアで左右スワイプによる写真切替
- ピンチで拡大縮小、拡大中の1本指ドラッグ移動
- 水平反転と拡大率のボタン操作
- 「共有・保存」からiOS共有シートで写真を書き出し（対応時）。非対応時はダウンロードへフォールバック
- タイトル「真写」からギャラリーへ戻る

## 公開・ホーム画面への追加
このフォルダの中身を独立したGitHubリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main / (root) を選択してください。公開URLをiPhoneのSafariで開き、共有 → ホーム画面に追加を選びます。

## 保存について
写真はこのiPhoneのブラウザのIndexedDBに保存され、サーバーには送信しません。iPhone版専用のデータベース `shinsha-iphone-library` を使用します。従来版のデータベース `shinsha-local-library` が同じブラウザ領域にある場合、初回起動時に写真をコピーして引き継ぎます。旧データは削除しません。

iOS Safariの仕様により、共有シートやファイル保存の表示はOSバージョン・起動方法で異なる場合があります。ブラウザのサイトデータ消去やストレージ管理により保存データが失われる可能性があります。元画像は別途バックアップしてください。

## 対応上の注意
写真アプリのアルバムを常時監視したり、自動同期したりする機能ではありません。読み込み時にユーザーが選択した写真だけを真写内へコピーします。
